# Jungle Airship — мод для Minecraft 1.12.2 (Forge)

Работает вместе с OptiFine (отдельный мод, ставится рядом в папку mods).

## Как собрать .jar (3 шага)
Нужен JDK 8 (не 21!). Самый надёжный способ — через MDK:
1. Скачай **Forge MDK 1.12.2 (14.23.5.2860)** с files.minecraftforge.net и распакуй в пустую папку.
2. Скопируй из этого проекта папку `src` в папку MDK (с заменой) и замени `build.gradle` на мой.
3. В папке запусти `gradlew build` (Windows: `gradlew.bat build`).
   Готовый мод: `build/libs/jungleairship-1.12.2-1.0.0.jar` — кидай в `.minecraft/mods`.

Для IntelliJ: `gradlew setupDecompWorkspace idea`, затем открой проект.

## Что делает мод
* Каждый новый обычный мир — джунгли (конфиг `forceJungle`), с ямами/разломами и редкими областями
  (болото, кристальная долина, костяная пустошь, ледяная роща).
* У спавна мира — расчищенная поляна, на ней дирижабль, уголь, факелы и железный топор.
* Дирижабль: ПКМ пустой рукой — сесть. W/S тяга, A/D поворот, Space вверх, Ctrl вниз.
  ПКМ углём/палками (не блоками) — топливо; блоки-топливо (дерево) — ПКМ с Shift.
* ПКМ любым обычным блоком по дирижаблю — поставить блок на корабль. Блоки добавляют вес, смещают
  центр масс (крен/дифферент). Shift+ПКМ пустой рукой — снять последний блок.
* Админ (`SuperKirill2020`, список в `config/jungleairship.cfg`): `/airship help`.
  `/airship disable <ник>` — отключает мод игроку навсегда (конфиг + данные мира), `enable` возвращает.

## Важно
* На серверах без лицензии (offline-mode) ник подделать легко — добавь свой UUID в `adminUuids`.
* На выделенном сервере поставь `allow-flight=true` в server.properties (иначе кик за «полёт» на дирижабле).
* Мод должен стоять и на сервере, и у игроков.
